# Sakura Manager Fresh

A newly created Android project based on the Sakura storefront and Supabase schema. This source is not extracted from the previous APK/source archives.

Build with Gradle 8.9 and Java 17: `gradle -p SakuraFresh assembleDebug`.

Current functions: Supabase email/password sign-in, product/inventory listing, order listing, and order status update via the store RPC.
